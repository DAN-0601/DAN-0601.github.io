접근하는 정보와 목적

계정 소유자의 승인으로 Gmail 계정 주소, 대상 메일의 발신자·제목·수신일·메시지 식별자·첨부파일 정보 및 명세서 PDF에 접근합니다. 목적은 대상 명세서 선택, 이미지 변환, 지정된 수신자에게 발송, 중복 발송 방지와 오류 확인입니다.

Gmail 권한

Gmail 읽기 권한과 전송 권한을 사용합니다. 승인 범위는 Gmail 읽기를 허용하지만 프로그램의 처리 대상은 운영자가 지정한 명세서로 제한합니다. Gmail 비밀번호를 수집하지 않으며 OAuth 인증정보로 연결합니다.

저장과 보관

인증정보와 PDF 비밀번호는 프로그램 소스와 분리된 비밀정보 저장 기능에 보관합니다. PDF와 생성 이미지는 처리 중 실행 환경에서 임시로 사용하고 작업 종료 시 정리합니다. 중복 방지와 운영 확인에 필요한 발송 식별자·연월·상태 등 최소한의 기록은 보관할 수 있습니다. 원본과 발송메일은 해당 메일 서비스에 남으므로 계정 소유자가 직접 삭제할 수 있습니다.

전달 및 실행 환경

운영자가 지정한 수신자에게 명세서 이미지를 이메일로 전달합니다. Google의 Gmail 서비스와 GitHub Actions 실행 환경을 이용하므로 업무에 필요한 정보가 이 서비스에서 처리됩니다. Google과 GitHub에는 각 서비스의 개인정보처리방침이 적용됩니다.

사용 제한

Google 사용자 데이터를 판매하거나 광고 목적으로 사용하지 않습니다. 명세서 내용은 AI 모델 학습에 사용하지 않습니다. 로그와 공개 저장소에 명세서 본문, 이미지, 비밀번호 또는 인증정보를 기록하지 않는 것을 운영 기준으로 합니다.

Google API에서 받은 정보의 이용 및 다른 앱으로의 전달은 Google API Services User Data Policy의 Limited Use 요구사항을 준수합니다.
